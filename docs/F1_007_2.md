# F1-007.2A / F1-007.2B (локальный DRAFT)

## Зачёты
- Δ = очки текущей строки минус очки предыдущей строки опубликованного зачёта. Первая строка, неклассифицированные и неизвестные очки — прочерк. Равные очки — 0. Дроби сохраняются. Порядок опубликованных строк не меняется; победы остаются видимыми.
- Золотая рамка и корона для первого места последнего зачёта завершённого сезона. Для незавершённого — только если строго недосягаем по известному календарю и подтверждённой шкале очков; не используется Монте-Карло, максимум для всех соперников, включая возможные замены, 2 машины у конструктора. При неизвестных/неполных сессиях или равенстве максимума метка не ставится. Предыдущие снимки не раскрывают итог сезона. Титул по текущему DRAFT не означает независимую историческую верификацию.

## Изображения
- 42 растровых флага (63 названия стран/демонимов) из Noto Emoji, https://github.com/googlefonts/noto-emoji, SIL OFL 1.1 для исходного шрифта; шрифт не распространяется. Флаги отражают обозначения национальности/страны в F1DB, а не фактический флаг допуска FIA на отдельном этапе (например, нейтральный статус).
- F1DB v2026.21.0: 526 ключей событий, 61 конфигурация, 39 автодромов, 132 пилота и 41 конструктор в диапазоне 2000–2026. Маппинг трасс по externalEventId + season + circuitId. Это каталог конфигураций данного архивного релиза, не автоматически обновляемый при смене конфигурации в новом релизе.
- `media.mjs` включает флаги и каталог; `visual-media.json` в репозитории пустой. По умолчанию показываются инициалы вместо фото/логотипов и сообщение вместо отсутствующей схемы. Пустой публичный пакет проверяется существующим манифестом сборки. Локальный пакет передаётся только явным параметром `build_preview --media`, не включается в облачную сборку. Фото/логотипы/схемы в поставке **не загружены**: DNS заблокирован. Сетевое наполнение требуется на ПК пользователя.
- Сборщик `tools/collect_media.py` использует точный CSV с SHA-256 исходного архива, для схем — исходники F1DB по тегу, точные layout ID и чёрный стиль; отбрасывает неоднозначные совпадения и активный SVG. F1DB / Jules Roy, CC BY 4.0: https://github.com/f1db/f1db/tree/main/src/assets/circuits. Сетевые пути и реальное содержимое SVG в среде не проверены; формат проверен на фикстурах.
- Фото: Wikidata P18 после сверки даты рождения P569 и названия страницы, Commons imageinfo с лицензией и авторством; только разрешённые CC BY/SA, CC0, public domain. Это проверка соответствия метаданных, не визуальное распознавание. Фото может быть не из выбранного сезона.
- Логотипы: `--logo-plan` ищет P154 и сохраняет кандидатов, не подключая их автоматически. После ручной проверки источника, лицензии, конкретных лет и применимости бренда подготовить JSON-массив `[{"id":"f1db:...","file":"Точное имя файла Commons.ext","years":[2000,2001]}]`. `--approved-logos` загрузит разрешённые изображения для этих годов. Один конструктор может иметь несколько разных исторических логотипов. Отсутствие свободного файла не заменяется произвольной современной эмблемой. Право публичного использования логотипа (в том числе товарный знак) требует отдельной проверки.
- В UI изображения из локального пакета загружаются без сетевых запросов при просмотре. Источники/авторы/лицензии доступны в разделе «Источники изображений». Пользовательские прогнозы и official.json не меняются.

## Windows (из корня проекта)
```powershell
.\.venv\Scripts\python.exe tools/collect_media.py --baseline private/managed-preview/site/official.json --archive private/f1db/f1db-csv.zip --output private/media-2000-2026 --tracks
.\.venv\Scripts\python.exe tools/collect_media.py --baseline private/managed-preview/site/official.json --archive private/f1db/f1db-csv.zip --output private/media-2000-2026 --photos --logo-plan
Get-Content private/media-2000-2026/media-report.json
.\.venv\Scripts\python.exe tools/build_preview.py private/managed-preview/site/official.json --output private/preview-design-002 --media private/media-2000-2026/visual-media.json
.\.venv\Scripts\python.exe -m http.server 8765 --bind 127.0.0.1 --directory private/preview-design-002
```
Повторный запуск использует сохранённые изображения, `--retry-missing` повторяет поиск отсутствующих. Если сеть недоступна, локальную сборку можно выполнить без `--media` и проверить зачёты/флаги. Для повторной сборки — новое имя каталога. `--source-zip` позволяет использовать вручную скачанный ZIP исходников того же тега, не стандартный CSV ZIP.
Не добавлять private/media-2000-2026 в Git и не публиковать до приёмки.
