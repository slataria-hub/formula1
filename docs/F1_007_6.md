# F1-007.6 — incremental DRAFT media synchronization

## Scope and invariants
- Current local media coverage confirmed by user: 132 photos, 286 team-season visuals, 61 track layouts. Historical/rights review remains pending. F1-007.5 dashboard visually accepted.
- Canonical future sync: `tools/sync_media.py`. The historical `collect_media.py` CLI remains available for the original pinned 2000–2026 collection and reviewed batches; use the new CLI for new releases/years. No changes to official schema, results, user predictions or localStorage keys.
- The sync consumes a structurally valid, nonempty DRAFT and exactly its F1DB CSV archive (source ID, SHA-256, stable tag, archive validation). Default cache path is `private/f1db/releases/<tag>/<sha256>/f1db-csv.zip`; legacy archive accepted only if digest matches. Explicit `--archive` supported. No guessing from latest release that may differ from the candidate.
- Event mapping binds provider race ID, year, round, date, circuit ID and source digest. Layout ID must belong to the circuit. Future events use `eventLayouts` in the media pack; legacy packs retain historical static map. If dynamic mapping is present but doesn't match the event source, no track is displayed. Historic layout IDs retained; no substitution by contemporary circuit layout. A different release may require resync before rebuilding an older preview.
- New photographs retrieved via the previous date-of-birth/Commons attribution checks. New track SVGs retrieved by exact ID from same-tag F1DB source archive; source ZIP checked for expected root, size limits, LICENSE CC BY 4.0 and README attribution, and exact safe SVG. Source ZIP SHA-256 recorded, not a publisher-provided digest. F1DB README: https://github.com/f1db/f1db/blob/main/README.md (Jules Roy / circuit SVG; CC BY 4.0). If source format or license changes, fail closed.
- For calendar-only seasons, prefetch rosters from archive season entrant tables if supplied; test drivers excluded. No speculative roster added to sporting data. During a season, discover new identities as official results/standings arrive. No annual year parameter. Existing 42 local flags reused; new unambiguous country-name aliases derived from CSV. New country without raster gets ISO text fallback, no invented flag.
- Team-season slots are exact. No automatic carry-forward or automatic approval of candidates. Discover and cache candidate file names; use initials until a reviewed `{id,file,years,periodStatus}` manifest is supplied with `--approved-logos`. Each year validated against observed roster/data. Existing visuals and status metadata never changed by sync. Historical and licensing review remains separate.
- Local only. Lock prevents concurrent sync; do not run legacy collector in parallel. Pack atomically replaced only if changed, prior exact bytes backed up under `backups/visual-media-<sha256>.json`. Successful images retained on individual network errors; interruption before final save leaves old pack intact. Subsequent runs retry missing images; cached candidate names reused for same archive. No_change preserves file bytes, no image network requests if fully populated. Plan-only does not change pack or fetch images. It writes `media-sync-plan.json`; sync writes `media-sync-report.json`. `draft_media_ready` means technical coverage only, not publishing permission. `draft_media_review_required` means unresolved slots or errors; exit 2 for operational errors, 1 for blocked preconditions, 130 cancelled. Reports are private. Remove a stale `.media-sync.lock` only after checking no sync process runs.

```
.\.venv\Scripts\python.exe tools/sync_media.py --baseline private/managed-preview/site/official.json --output private/media-2000-2026 --plan-only
```
Expect 27 seasons, 526 events, 132/286/61 and zero missing. Then run the same command without `--plan-only`, inspect report, and repeat; second run should show `packChanged=false`. If the baseline's exact archive cannot be found, supply `--archive private/f1db/f1db-csv.zip` only if it has matching SHA-256. Build a new preview with `--media private/media-2000-2026/visual-media.json`; same HTTP origin to retain browser predictions. Do not delete old media or previews.

## Future local DRAFT preparation integration
`prepare_update.py --baseline <active official> --output <new private run directory> --media-output private/media-2000-2026` now optionally triggers sync on the audited candidate and its verified cached archive. No automatic activation. Media error returns code 2; audited data candidate remains valid and retryable separately. On success with pending logos, still DRAFT; see report. This is a local opt-in pipeline, not an enabled production scheduler. Cloud persistence / public deployment / scheduled sync remain gated by F1-008 and explicit approval, including packaging media and remote rollback. Do not commit private media/archives or publication artifacts.
