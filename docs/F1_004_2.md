# F1-004.2 — календарь, сезонный H2H и статистика

Локальная предварительная версия, только чтение. Основана на F1-004.1, принятой по журналу пользователя: 100 Python-тестов, сборка 27 сезонов, HTTP 200 для всех основных ресурсов. Исходный `index23.html` и база не меняются.

- Календарь: трасса/страна, дата, статус, победитель, первая позиция квалификации (поул в интерфейсе), фильтры всех/завершённых/незавершённых этапов. Нет вымышленных результатов.
- H2H: сравнение пары пилотов только внутри одной заявки (или конструктора, когда явной заявки нет) и одной сессии завершённого этапа. Гонка: оба стартовали и классифицированы; квалификация: оба имеют классифицированную позицию. Равенства и исключённые сравнения показаны отдельно; отсутствие одного участника не считается поражением. Гонки и квалификации отдельно, спринты не включены. Составы по этапам остаются доступными.
- Статистика пилотов: старты, победы, подиумы, первые позиции квалификации, быстрейшие круги, сходы (retired при подтверждённом старте). Очки берутся из последнего снимка зачёта. Спринты не включены в гоночные победы/подиумы. Сортировка выбирается пользователем. Первое место квалификации не обязательно совпадает со стартовой позицией после штрафов.
- Встроенная SVG-иконка вкладки; адаптивная верстка.

Проверка: `node --test tests/test_preview_model.mjs` (12 тестов), `python -m unittest discover -s tests -v` (100 тестов), сборка реальной базы и Chromium DOM smoke. Chromium получает данные напрямую в тесте, а не через HTTP. Локальный HTTP проверяется пользователем. Node нужен только для JS-тестов, не для сайта.

Сборка в новую папку (предыдущую не удалять):
```
python tools/build_preview.py private/f1db-all-f10033-reviewed.json --output private/preview-v2-2
python -m http.server 8765 --bind 127.0.0.1 --directory private/preview-v2-2
```

Ограничения: draft не публикуется. H2H не является официальным зачётом, методика явно указана. Полный исходный функционал, графики, произвольное H2H, прогнозы, независимая историческая приёмка и автообновление ещё предстоят. Старый тестовый прогноз не переносить. Автоматическое обнаружение и загрузка будущих сезонов без ежегодной правки кода, защита пользовательских данных и откат остаются обязательными.
