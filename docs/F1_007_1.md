## Установка и локальная проверка
Из корня проекта, после распаковки патча:
```powershell
.\.venv\Scripts\python.exe tools/build_preview.py private/managed-preview/site/official.json --output private/preview-design-001
.\.venv\Scripts\python.exe -m http.server 8765 --bind 127.0.0.1 --directory private/preview-design-001
```
Остановить прежний сервер перед второй командой. Использовать тот же браузер, origin и порт, не очищать localStorage. Старый managed-preview не перезаписывается; для возврата запустить сервер из прежнего каталога. Если каталог preview-design-001 уже существует, выбрать новое имя.

Проверить 2026 (23 этапа, 21 завершён, Qatar, лидеры 402/666 в текущем снимке), 2000 (17 этапов, McLaren 152), 2021 (395,5 очка), переключение тем, напарников, прогноз Катара, расчёт титула. В devtools проверить ширину 390 px. Не переносить старый тестовый прогноз legacy. Не делать merge main или деплой.
