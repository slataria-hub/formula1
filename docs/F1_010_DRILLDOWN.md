# F1-010 — интерактивная детализация аналитики

Зафиксировано по просьбе пользователя 2026-11-28. Выполнять после текущего плана, отдельно от F1-009.

- В дашборде «Победы в гонках» клик по пилоту открывает список выигранных им гран-при выбранного сезона, по дате, только окончательные классификации гонок, без спринтов.
- Клик по этапу открывает существующую полную карточку гран-при со всеми вкладками и результатами.
- Кнопка «Назад» возвращает в предыдущий контекст: из гран-при к победам пилота, из списка побед к дашборду. Поддержать стандартную кнопку браузера. Сохранять выбранный сезон, пилота, фильтры и позицию прокрутки.
- Не менять официальный источник, расчёт побед, сохранённые прогнозы. Проверить возврат, сезон без побед, историю браузера и мобильную адаптацию.
- Возможное развитие после реализации и согласования: аналогичная детализация подиумов, поулов, быстрейших кругов, сходов, побед конструкторов.
