# F1-009 — интеллектуальное прогнозирование результатов гран-при (после текущей разработки)

Зафиксировано 2026-11-28 по просьбе пользователя: после завершения разработки приступить к анализу трасс (автодромов), характеристик пилотов, команд и других факторов для прогнозирования победы в различных гран-при.

Предлагаемая детализация (не утверждённая модель и не реализация):

1. Каталог характеристик автодромов по конфигурации и периоду: длина, повороты, тип покрытия, скорости, прижимная сила, возможности обгона, деградация шин; источники, единицы, неопределённость.
2. Признаки пилотов: квалификационный/гоночный темп, результаты на аналогичных трассах, стабильность, старты, обгоны, ошибки, опыт, форма; различать вклад пилота и машины.
3. Признаки команд/болидов: темп, эффективность на разных типах трасс, надёжность, обновления, стратегия, пит-стопы; учитывать изменения регламента и состава.
4. Факторы конкретного уик-энда: погода, шины, квалификация, стартовая решётка и штрафы, по мере доступности данных до момента прогноза.
5. Базовая модель, затем сравнение более сложных методов. Оценка вероятности победы/подиума, неопределённость и объяснение факторов. Не смешивать с существующей моделью шансов на титул и пользовательскими прогнозами.
6. Воспроизводимый walk-forward backtest без утечки будущих данных: отдельные срезы до уик-энда и после квалификации; сравнение с простыми базовыми моделями, калибровка вероятностей, log loss/Brier score, качество по эпохам и трассам. Не обещать гарантированного победителя.
7. Проверка лицензий источников, отсутствие данных — явный пропуск; автоматическое добавление новых сезонов без правки года. Публикация только после отдельной приёмки.
