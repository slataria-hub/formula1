# F1-004.3 — динамика чемпионата и сравнение пилотов

Дополнение к локальному read-only интерфейсу F1-004.2. Скриншоты пользователя подтвердили отображение трёх вкладок предыдущей поставки; локальный протокол тестов F1-004.2 не предоставлен.

- В Дашборде два режима: «Статистика» и «Графики и сравнение». Существующая статистика сохранена.
- Два произвольных пилота выбранного сезона, в том числе из разных команд. По умолчанию первые два участника последнего опубликованного зачёта; если их меньше — доступные участники. При смене сезона выбор обновляется. Идентификаторы, не фамилии.
- Динамика очков и мест после каждого этапа: только опубликованные snapshots drivers. Не суммировать очки заново. Отсутствие строки, снимка или числовой позиции — null; разрывы не соединяются. Нулевые и дробные очки, отрицательная динамика после санкций сохраняются. Место 1 наверху.
- Выбор этапа выделяет вертикальную линию и обновляет таблицу точных значений. Наведение на точку даёт подсказку. Сезонные статистические показатели обоих пилотов представлены отдельной таблицей; это не H2H.
- SVG без внешних библиотек, адаптивные селекторы и горизонтальная прокрутка графика на телефоне. Два цвета и разные стили линий. Node только для тестирования.
- Источник данных, JSON Schema, предыдущие прогнозы, исходный index23.html и стабильная ветка main не изменяются. База draft. Никакой публикации.
