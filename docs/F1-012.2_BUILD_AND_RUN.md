## Windows / PowerShell

1. После решения архитектора скачать ZIP в Downloads и распаковать **вне проекта**. Если имя/папка загрузки отличаются, поправить `$zip`. Требуется Python из существующего окружения проекта.

```powershell
$project = 'C:\Users\Gigabite\Desktop\Project\F1-Analytics'
$zip = "$HOME\Downloads\F1_012_2_1_STATIC_HOSTING_PATCH.zip"
$patch = "$HOME\Downloads\F1_012_2_1_STATIC_HOSTING_PATCH"
$py = "$project\.venv\Scripts\python.exe"
Expand-Archive -LiteralPath $zip -DestinationPath $patch
& $py "$patch\apply_f10122.py" --project $project
```

Ожидается `PREFLIGHT_OK: 176 base files; ... changes`. При любой ошибке не продолжать. Скрипт только читает HEAD и исходники; не коммитит, не пушит. После GO проверить отсутствие рабочей ветки и создать её локально; при существующей ветке остановиться и согласовать. Незакоммиченные F1-007.* должны сохраниться.

```powershell
Set-Location $project
git branch --list feature/f1-012-2-static-hosting
# Только если команда не вывела ветку:
git switch -c feature/f1-012-2-static-hosting
& $py "$patch\apply_f10122.py" --project $project --apply
```

Ожидается `APPLY_OK; backup: ...`. Апплаер проверяет все 176 SHA, состав и SHA payload, сохраняет копии заменяемых файлов и манифест в private/f101221-patch-backup-*, проверяет результат и откатывает записанные файлы при ошибке. Не распаковывать files/ напрямую поверх проекта.

2. Создать локальную и Pages-репетицию из одинаковых входов. Указанные пути подтверждены снимком пользователя. Каталоги вывода должны отсутствовать. При повторении выбрать новые имена **в обеих командах и smoke**. При несовпадении контрольных сумм входов — остановиться, не править манифест для обхода проверки.

```powershell
$official = 'private/managed-preview/site/official.json'
$media = 'private/media-2000-2026/visual-media.json'
Copy-Item reports/F1-012.2_MEDIA_REHEARSAL_MANIFEST.json private/f101221-media-manifest.json
$review = 'private/f101221-media-manifest.json'
& $py tools/build_preview.py $official --output private/f101221-local --media $media --media-manifest $review --manifest
& $py tools/build_preview.py $official --output private/f101221-pages/formula1 --media $media --media-manifest $review --mode pages --rehearsal
```

3. Браузерный smoke сам поднимает два HTTP-сервера на случайных портах loopback, создаёт независимые временные браузерные контексты и закрывает их. Не нужно отдельно запускать серверы или использовать свой профиль браузера. Установка Playwright/Chromium нужна только для тестов, а не для приложения. Если Playwright и Chromium уже установлены, пропустить установку.

```powershell
& $py -m pip install playwright
& $py -m playwright install chromium
& $py tools/smoke_static_hosting.py --local private/f101221-local --pages private/f101221-pages --output private/f101221-browser.json
Get-Content private/f101221-browser.json
```

При наличии другого совместимого Chromium можно указать `--chromium 'C:\path\to\chrome.exe'`. Скрипт использует только синтетический прогноз в новых контекстах; виртуальные часы проверяют дедлайн, не подтверждают дату реального прогноза. Ожидается exit 0 и все PASS; при BLOCKED/FAIL не считать браузерную приёмку выполненной. Передать только `private/f101221-browser.json` и вывод ошибок, если они есть; реальные прогнозы не передавать.

```bash

"$py" -m pip install -r requirements.txt
"$py" "$patch/apply_f10122.py" --project "$project"
git branch --list feature/f1-012-2-static-hosting
```

Если системный Chromium установлен, можно указать `--chromium /usr/bin/chromium`. При недостатке системных зависимостей — BLOCKED, не менять настройки защиты без согласования.

## Шлюзы и совместимость

Старая локальная CLI `build_preview.py input --output private/new [--media private/media.json]` остаётся работоспособной; при старой CLI манифест не появляется автоматически. Проверено также на реальных компактных спортивных данных и реальном медиапакете. `prepare_publication.py build` для пустого штатного пакета требует явный `--synthetic`, либо `--media` с `--media-manifest` и отдельной подтверждённой проверкой прав. Synthetic означает только синтетический медиапакет, а спортивные данные могут быть реальными DRAFT. Права не утверждены, `publicationAuthorized=false`, `independentVerification=pending`. Никаких данных в f1-data не записывается. Верификация видимости workflow artifact — F1-012.3, не запускать облачный workflow в рамках текущей задачи. При переносе backup старые записи с актуальной привязкой поддерживаются; намеренно непривязанные записи остаются архивными, проверка `prepare_update --user` по прежнему fail closed, никаких данных не удаляет.
