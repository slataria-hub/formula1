# F1-002 — пробный импорт (итерация 1)

База: v0.1.0 (792c603), ветка feature/f1-002-historical-import. Контракты не изменены. Пилот не является релизом 0.2.0.

Из корня репозитория на Windows:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tools/import_data.py --season 2000 --output private/candidate-2000.json
.\.venv\Scripts\python.exe tools/validate_data.py private/candidate-2000.json
```

Jolpica F1: https://github.com/jolpica/jolpica-f1/tree/main/docs . Календарь, результаты гонок/квалификации/спринтов (2021+), опубликованные последние зачёты сезона, лучший круг при наличии ранга 1. Запросы постраничные, кеш по URL с SHA-256 и временем получения, тайм-аут, ограничение частоты и повторы сетевых сбоев. Кеш по умолчанию private/jolpica-cache; не публиковать его. Для повторного получения данных используйте `--refresh` с новым именем кандидата. Кеш можно повторно использовать после прерванного запуска; существующий кандидат не перезаписывается. Атомарное создание через hard link требует поддержки файловой системой (NTFS обычно поддерживает). Если файловая система не поддерживает, импорт завершится ошибкой, не изменив прежнюю базу.

Валидация структуры выполняется перед созданием файла. Состояние всегда draft; `--release` должен его отклонять. При нехватке результатов выводятся предупреждения. Отдельные показатели статусов могут оставаться unknown/null, пока не проверена семантика поставщика; квалификационная классификация не угадывается. Время начала сессии берётся только при наличии даты и времени. Исторические корректировки очков, независимая сверка, перенос пользовательских прогнозов, OpenF1 и объединение сезонов не реализованы в этой итерации.

Контроль 2000: 17 этапов, Михаэль Шумахер 108 очков, Ральф Шумахер 24; отдельные ID и разные конструкторы. Сопоставить опубликованный итоговый зачёт с Formula1.com/FIA, а также сравнить суммы с официальными очками результатов и выявить исключения. Синтетические тесты не являются проверкой чемпионата. Реальный API из среды подготовки недоступен (DNS); пробный запуск на ПК обязателен.
