# F1-004.1 — локальная адаптация интерфейса (пилот)

Предпосылка: F1-003.3. Пользователь исключил перенос старого тестового прогноза. Эта поставка включает файлы F1-003.3 для воспроизводимости, а также новый интерфейс. Исходный index23.html, исходный data.json, приватные файлы и опубликованный сайт не изменяются.

## Что реализовано
- Отдельный локальный просмотрщик v2 (`web/preview`), исходные CSS/палитра и навигационная концепция сохранены; это не полный перенос старого приложения.
- Генератор `tools/build_preview.py` валидирует непустую draft-базу и создаёт только новый подкаталог `private/`, не перезаписывает существующий каталог; копирует лишь четыре статических файла и `official.json`. Не публиковать полученный каталог.
- Сезоны выводятся по календарю, максимальный доступный год автоматически выбран. Будущие события без результатов не заполняются вымышленными данными.
- Этапы, результаты сессий (гонка/квалификация/спринт/спринт-квалификация), источник, лучший круг при наличии. Неклассифицированная числовая исходная позиция не выдаётся за место.
- Матрица очков по пилотам; гонка+спринт по начисленным очкам, итоговая строка — опубликованный снимок зачёта. Зачёты личный/командный по выбранному этапу; отдельные заявки Force India 2018. Не пересчитывать штрафы.
- «Напарники»: участники команды/заявки на выбранном этапе. «Дашборд»: базовая сводка покрытия сезона. Полный H2H, графики, прогнозы, настройки, редактирование и публикация пока отсутствуют. Просмотрщик не читает и не изменяет localStorage, user-v2.json или старые прогнозы.

## Запуск (PowerShell из корня)
```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
# Если F1-003.3 ещё не прогнан (новые пути, не перезаписывать):
.\.venv\Scripts\python.exe tools/review_remaining.py private/f1db-all-f1003-reviewed.json --secondary private/candidate-2000.json --output private/f1db-all-f10033-reviewed.json --report private/f10033-review.json
.\.venv\Scripts\python.exe tools/audit_championships.py private/f1db-all-f10033-reviewed.json --report private/f10033-audit.json
.\.venv\Scripts\python.exe tools/init_user_data.py private/f1db-all-f10033-reviewed.json --output private/user-v2.json
.\.venv\Scripts\python.exe tools/check_update.py private/f1db-all-f1003-reviewed.json private/f1db-all-f10033-reviewed.json --user private/user-v2.json
.\.venv\Scripts\python.exe tools/build_preview.py private/f1db-all-f10033-reviewed.json --output private/preview-v2
.\.venv\Scripts\python.exe -m http.server 8765 --bind 127.0.0.1 --directory private/preview-v2
```
Открыть http://127.0.0.1:8765/ в браузере. Сервер раздаёт только сформированный каталог; остановить Ctrl+C. Не запускать из общего private или корня репозитория. При повторной сборке указывать новый подкаталог, например private/preview-v2-next. Если файлы F1-003.3 уже существуют, не создавать их повторно, проверить существующие.

## Ограничения и последующие итерации
Проверка Chromium выполнена с прямой подачей реального JSON и кода в DOM: локальная HTTP-навигация в среде разработки заблокирована. Фактический HTTP-запуск проверить на ПК пользователя. База остаётся draft. Не переносить старый тестовый прогноз; новые реальные прогнозы реализовать отдельно, привязывать к устойчивым ID и не перезаписывать при обновлении. Автообновление новых сезонов через GitHub Actions, загрузка релизов F1DB, gate проверки, сохранение последней исправной базы и безопасная публикация обязательны, но не реализованы в этом пилоте. Список сезонов уже динамический.
