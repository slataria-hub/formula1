# F1-003.3 — точечная сверка и чистый пользовательский старт

## Объём поставки
- Применять `review_remaining.py` после `reconcile_f1db.py`. Две перестановки мест после этапов 2021 R10 и 2022 R06; проверяются исходные позиции и очки. Очки, гонки, идентификаторы и исходный кандидат не изменяются. Повторная коррекция идемпотентна. Источники: документ FIA Championship Points (British GP 2021), таблицы RaceFans и Crash.net после Spanish GP 2022.
- 2012 R06 остаётся спорным; два кандидата countback 2000 относятся к ранее проверенному порядку официального зачёта. Тест countback является эвристикой, а не нормативным пересчётом.
- `review_remaining.py` уточняет расхождения позиций между источниками по статусам. Справочник совпадений 23 пилотов сезона 2000 остаётся набором кандидатов, а не автоматически утверждёнными alias; сопоставления команд и трасс также не утверждены. 12 расхождений времени в 1 мс, 3 различия статусов, пробелы источника и одно расхождение квалификационного времени остаются в отчёте. Не подменять неизвестные данные догадками.
- По указанию пользователя исходный прогноз был тестовым: НЕ переносить его, не извлекать для новой базы, не удалять резервную копию. Миграция старых прогнозов исключена из обязательных задач. `init_user_data.py` один раз создаёт пустые predictions и overrides и выбирает максимальный сезон в календаре. Файл не перезаписывается. После начала реального использования пользовательский файл НЕ инициализировать повторно; проверять совместимость с новыми официальными данными.
- Автоматическое обновление будущих лет обязательно. На этапе 03: обнаружение свежих релизов, импорт без фиксированного последнего года, reconcile_f1db + review_remaining.correct (коррекции без необходимости вторичного источника), аудит, проверка совместимости с действующей базой и новым пользовательским файлом, безопасная публикация и откат. При неуспехе сохранить предыдущий снимок. Планировщик пока не реализован.

Ожидаемые результаты на зафиксированном архиве F1DB: две перестановки мест, 23 кандидата ID, 17 142 проверки очков, 20 известных исключений, 0 issues, 3 countback candidates, 32 группы равных мест. REVIEW REQUIRED сохраняется. Пустой пользовательский файл создаётся только при отсутствии файла по указанному пути. Все выходы новые, не перезаписывают входы.
