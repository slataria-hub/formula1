# F1-004.4 — локальные прогнозы и настройки

Локальная предварительная версия DRAFT. Скриншот F1-004.3 подтверждает отображение графика сезона 2021 на ПК пользователя; отдельный протокол локальных тестов F1-004.3 не предоставлен.

## Возможности
- Карточка Гран-при → «Прогноз»: от 1 до 10 разных пилотов в порядке финиша, перемещение, удаление, сохранение и отмена несохранённых изменений. Только гонки, не спринты. Список пилотов по наблюдаемым участникам сезона (при их отсутствии — предыдущего доступного сезона), а не гарантированная стартовая заявка.
- Дашборд → «Мои прогнозы»: прогнозы выбранного сезона, переход к этапу, оценка после окончательных результатов. Старая формула приложения сохранена: точное место +5, отклонение на одну позицию +2, победитель +10, каждый угаданный участник подиума из первых трёх прогнозируемых мест +3. Используются числовые классифицированные места стартовавших пилотов; без полного подиума оценка недоступна. Это оценка прогноза, а не очки чемпионата.
- Автоматическая/светлая/тёмная тема; последний выбранный сезон сохраняется. Годы берутся из базы.

## Хранение и ограничения
- Ключ localStorage `f1-analytics:v2:user:1`. Новый пустой пользовательский набор; legacy/data.json и старые тестовые прогнозы не читаются и не переносятся. Официальный JSON не изменяется. Учитывается origin (схема, хост, порт) и профиль браузера. При одинаковом origin новый каталог сборки не очищает прогнозы.
- Контейнер `{version:1,user:{schemaVersion:'2.0.0',predictions,overrides,preferences},bindings}`; поле user соответствует пользовательской модели (ручные override пока не поддерживаются). bindings хранит внешний ID гран-при, сезон и тип сессии. При изменении или коллизии ID сессии/события запись сохраняется, но не переносится автоматически и редактирование блокируется. Шлюз безопасного обновления и автоматическая миграция перенумерованных этапов — дальнейшие задачи.
- Запись только до дедлайна и только для запланированной гонки без результатов. При наличии точного времени с часовым поясом — до старта; иначе консервативно до самого раннего начала календарного дня гонки в UTC+14 (14:00 часов вычитаются из полуночи UTC). Местное время показывается в интерфейсе. Это клиентская проверка, не серверная защита от изменения системных часов или хранилища.
- При недоступном/повреждённом хранилище приложение не перезаписывает данные. Обнаружение изменений другой вкладкой перед записью не заменяет транзакционное многопользовательское хранилище. Экспорт JSON-контейнера через «Мои прогнозы» доступен; интерфейса восстановления/импорта, синхронизации устройств и серверных аккаунтов пока нет. Экспортируемый контейнер не передаётся напрямую в Python-валидатор user schema: отдельный адаптер для bindings предстоит.
- База остаётся draft; не публиковать, не изменять main, старую страницу или архивы. Автозагрузка календарей/результатов будущих лет ещё не реализована.

## Локальная приёмка
```
python -m unittest discover -s tests -v
node --test tests/test_preview_model.mjs tests/test_preview_user.mjs
python tools/build_preview.py private/f1db-all-f10033-reviewed.json --output private/preview-v2-4
python -m http.server 8765 --bind 127.0.0.1 --directory private/preview-v2-4
```
Проверить будущую гонку (если срок ещё не истёк), добавить 2–3 пилотов, поменять порядок, сохранить, перезагрузить страницу, открыть «Мои прогнозы», проверить порядок и тему. Закрытые гонки не редактируются. Проверить экспорт. При уже истёкшем сроке не менять часы ПК ради обычной проверки: проверить доступную будущую гонку или только режим просмотра. Для сохранения данных между локальными сборками использовать тот же адрес http://127.0.0.1:8765/ и тот же профиль браузера.
